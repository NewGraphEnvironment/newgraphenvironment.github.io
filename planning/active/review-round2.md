## Findings

- **F1 [qualifier dropped]** OSS:52, "Our climate analysis tool, cd (below), compares flow during key life stages, such as chinook migration and spawning, with long-term normals, and water temperature with the recent record." It comes straight after "The flow can feed the habitat rules", which is the per-stream segment flow, so a reader takes the life-stage comparison to run for every stream. wet README: "**Station flow.** Daily flow from HYDAT…summarised per year over month-day windows for cd's departure statistics". The segment path gives only mean annual and monthly flow, with no per-year series to window. The #53 copy said "The station windows, run through cd". Suggested: "At gauging stations, our climate analysis tool, cd (below), compares…".
- **F2 [qualifier dropped, minor]** OSS:116, "Georeferenced photos are served in our airphoto catalogue, stac_airphoto_bc." The catalogue holds thumbnails only. stac_airphoto_bc README: "serve georeferenced historical aerial photograph thumbnails"; fly README "Used by": "georeferenced historic airphoto thumbnails". The same paragraph and the table (OSS:203) say thumbnails, so the page agrees with itself at the sentence before and disagrees here, the same class as round 1's fly finding. Suggested: "The georeferenced thumbnails are served in…".
- **F3 [overstated; introduced by fix 10a7cea]** OSS:22, "It builds on the methods of bcfishpass, the established fish passage model for BC." No source calls bcfishpass "the established" model. bcfishpass README: "a collection of scripts to create and maintain an aquatic connectivity / fish passage database for British Columbia". link README: "link's access model follows the method of bcfishpass, built by Simon Norris and maintained with contributions from many groups." Suggested, crediting without characterising: "It builds on the methods of bcfishpass, the fish passage model built by Simon Norris."
- **F4 [qualifier dropped, minor/borderline]** OSS:102, "watershed groups can't be compared with each other on hectares lost." stac_floodplains_bc README: "**Cross-group comparison is not valid yet.** With no treed-area denominator, a group whose floodplain is mostly open water cannot be set against a forested one on hectares lost." The README's claim is unconditional, and hectares lost is its example. Limiting the page to "on hectares lost" implies that other cross-group comparisons (gain, net, share of floodplain) are valid. They suffer from the same missing denominator. Suggested: "watershed groups can't be compared with each other."
- **F5 [overstated, minor]** OSS:192, "Each catalogue is two things: the data, and the public code that builds it". For stac_dem_bc and stac_pointcloud_bc the catalogue holds records that point at the province's files. stac_pointcloud_bc README: "An index, not a copy…No point data is copied". A live `stac-elevation-bc` item's `dem` href is `https://nrs.objectstore.gov.bc.ca/gdwuts/094/094o/2026/dem/…tif`. Read beside "We don't need to be the only source of this data", "the data" suggests we host LidarBC's tiles. Suggested: "the catalogue itself, and the public code that builds it".
- **F6 [naming order, author decision]** The tool headings name the package before the plain words: OSS:20 "link — …", OSS:48 "wet — …", OSS:86 "drift — …" and OSS:178 "water-temp-bc — …" are changed on this branch; fresh, flooded, fly and cd are unchanged. The hex image alt text above each heading (unchanged) is also the bare name. The prose under every heading does introduce the tool in plain words first. If the issue #56 acceptance line ("introduced in plain words before its name") is meant to cover headings, they would read "Habitat potential, species by species (link)". Otherwise the "name — gloss" heading counts as the introduction, and this needs only a recorded decision, as the landing chips got. The third-party names are each glossed in the clause that follows: bcfishpass (OSS:22) and fwapg (OSS:36).

No private names, comparisons with other organisations, counts of published items, or roadmap wording in any added line.
